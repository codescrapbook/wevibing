This is a sample post.

We’ll start with what we call “vibe coding”: describe the destination, accept imperfect drafts, and iterate quickly. The point isn’t to be sloppy — it’s to get signal fast, then tighten the loop with tests and structure.

Key ideas:

- Describe outcomes, not line-by-line steps
- Keep diffs small; ship something working
- Save structure (types, modules, tests) for pass two

We’ll practice across languages, tools, and agent stacks. Stay tuned.
